WBA Orçamentos - projeto Android (app em WebView, funciona sem internet)

COMO GERAR O APK

Opção A - sem instalar nada (GitHub):
 1. Crie um repositório no github.com e envie todo o conteúdo desta pasta (inclusive a pasta .github).
 2. Aba "Actions" > "Gerar APK" > "Run workflow".
 3. Ao terminar, baixe "WBA-Orcamentos-APK" (arquivo app-debug.apk).

Opção B - Android Studio:
 1. Abra esta pasta no Android Studio e aguarde o Gradle sincronizar.
 2. Menu Build > Build Bundle(s) / APK(s) > Build APK(s).
 3. O arquivo fica em app/build/outputs/apk/debug/app-debug.apk.

INSTALAR NO CELULAR (Android 10 ou superior)
 Envie o APK ao celular, abra o arquivo e permita "instalar apps desconhecidos" quando o Android pedir.

NOTAS
 - Os dados ficam salvos só no celular. Para passar a tabela ao outro celular: Administração > Dados > Backup (JSON) e, no outro, importar o backup.
 - PDF e imagem são salvos em Downloads e abrem o menu de compartilhar (WhatsApp etc.).
 - Para mudar o app, edite app/src/main/assets/index.html.
 - APK de teste (debug). Para publicar na Play Store é preciso assinar uma versão release.
